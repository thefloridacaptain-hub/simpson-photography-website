Batch gallery importer

Turn a folder of photographs into one website update.

This tool works inside your browser. Selected originals are processed on your device and are not uploaded by this page. It creates reduced-size, visibly watermarked previews—never use the exported files as customer downloads.

Keep your masters private.Do not upload original full-resolution files to GitHub or the public website. Upload purchased master files only to your secured digital-delivery provider.
1

Choose common settings

These apply to every selected photograph. You can adjust titles individually before exporting.

2

Select many preview source files

JPG, PNG and WebP are supported. For better speed, use copies smaller than 15 MB each.

3

Create the update package

The export contains only watermarked previews, thumbnails and the gallery catalog.

After the download

Upload one prepared package—not every product by hand.

  1. Unzip scott-simpson-gallery-update.zip.
  2. Upload its assets folder into the same location in your GitHub repository.
  3. Create the desktop and print-ready products with your checkout provider, then paste their URLs into gallery-data.js.
  4. Vercel publishes the GitHub update automatically.

The included README gives click-by-click instructions.
