# Scott Simpson Photography

Premium, dark, image-first photography storefront for downloadable personal-use licenses.

## What is included

- Production Scott Simpson Photography vector logo system
- Responsive gallery and photograph dialogs
- Three license tiers: Personal Screen ($15), Standard Personal Print ($65), and Full-Resolution Personal Print ($99)
- Lemon Squeezy checkout-overlay support
- Browser-based batch gallery importer
- Watermarked public previews and thumbnails
- Static-site validation script
- Vercel configuration

## Important commands

```bash
npm install
npm run check
npm start
```

Read `README-BEGINNER.md` for exact GitHub and gallery instructions.

Never upload clean customer files, RAW files, full-resolution masters, or Lemon Squeezy secrets to GitHub. Only watermarked previews and thumbnails belong in this repository.
